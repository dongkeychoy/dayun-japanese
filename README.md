# 다윤이의 일본어 미션 · DAY 01

`dongkeychoy/dayun-japanese`만 수정한 모바일 일본어 학습장입니다. 기존 CHOY 앱과 배포 설정은 수정하지 않습니다.

## 학습 화면

- **훈련:** 사용자 제공 걷는 여자아이 이미지, 行く의 7가지 활용형. 한 줄마다 변화형명·한자 활용형·바로 아래 히라가나·한국어 뜻·듣기 버튼을 표시합니다. 모든 레벨에서 7줄을 유지합니다.
- **문장:** 요청한 생활 문장 7개를 한 화면에 표시합니다. 일본어 → 히라가나 → 변화형명과 한국어 해석의 순서로 읽고 각 줄에서 바로 들을 수 있습니다.
- **오늘의 단어:** 学校·公園·塾·本屋·駅. 사진을 포함한 카드 한 장씩 이전/다음으로 이동합니다. 단어와 문장의 듣기 버튼을 각각 제공하며, 예문·후리가나·해석은 문장 데이터에서 직접 재사용합니다.
- **퀴즈:** 7문항, 4지선다, 즉시 점수 갱신, 정답 애니메이션·축하음·박수, 부드러운 오답 표시·효과음, 재도전, 점수 저장을 유지합니다. 답을 고른 뒤 다른 탭에 다녀와도 다음 문제로 진행할 수 있습니다.
- 아빠 점검과 기존 `localStorage` 기록 키를 유지합니다. 레벨에 따른 문제 난이도 차등화는 현재 구현되어 있지 않습니다.

## 화면 잘림 방지

여러 CSS 보정 파일을 겹쳐 사용하던 실행 경로를 `study.css` 하나로 정리했습니다. `100dvh`와 기기 안전 영역을 반영하고, 헤더·탭·하단 영역을 제외한 남은 높이를 7줄에 나눕니다. 학습 내용을 `overflow: hidden`, 말줄임, 줄 수 제한 또는 축소 변환으로 가리지 않습니다.

훈련은 대표 이미지를 유지하고 작은 화면에서는 장식을 줄입니다. 문장은 긴 일본어와 후리가나에 가로 공간을 주도록 변화형명을 해석 옆에 배치합니다. 문장·단어·퀴즈에서는 훈련용 대표 영역을 숨겨 핵심 학습 공간을 확보하고, 단어 카드 상단에는 해당 단어의 사진을 표시합니다. 학습 듣기·단어 이동·퀴즈 선택/다음 버튼의 터치 영역은 최소 44×44px입니다.

## 실제 실행 파일

| 파일 | 역할 |
| --- | --- |
| `public/index.html` | 공통 HTML, 탭, 기존 설정/아빠 점검 대화상자 |
| `public/study.css` | 모든 모드의 단일 실행 스타일과 화면 높이 대응 |
| `public/day01.js` | 활용형·문장·단어·예문 연결 및 사진 출처 데이터 |
| `public/runtime.js` | 렌더링, 음성 재생, 퀴즈, 효과음, 기록 저장 |
| `public/images/` | 사용자 이미지, 사진 5장, `SOURCES.md` 출처/라이선스 |
| `public/audio/` | 활용형 7개·문장 7개·단어 5개의 일본어 MP3 |
| `public/_headers` | 기존 보안 헤더와 HTML/JS/CSS 캐시 재검증 |

예전 `app.js`, `lessons.js`, `style.css`, `visual-hotfix-20261103.css`, `one-line-7-v4.css`, `dayun-v5.css`는 현재 HTML에서 사용하지 않습니다. 새 수정을 할 때는 위 실행 파일을 편집하세요.

음성은 앱 내부 MP3를 우선 재생하고, 파일 재생 실패 시 브라우저 `ja-JP` TTS로 재시도합니다. 일본어 음성팩이 없는 브라우저에서도 MP3를 들을 수 있고, 앱 실행 중 외부 TTS 서버를 요청하지 않습니다. 효과음 설정은 발음 듣기와 별개입니다. 사진의 저작자·라이선스는 카드와 [이미지 출처](public/images/SOURCES.md)에 표시합니다.

## 실행과 검증

```sh
npm ci
npm start
npm test
npm run test:mobile
```

`npm start` 미리보기: `http://localhost:4173`. 모바일 검증은 `dist`를 빌드하고 자체 서버를 연 뒤 실제 Chromium에서 실행합니다. 시스템 `/usr/bin/chromium`이 없으면 `npx playwright install chromium`을 먼저 실행하거나 `CHROMIUM_PATH`로 브라우저 경로를 지정하세요.

- `npm test`: 요청한 7가지 활용형·문장·단어의 정확한 내용, 예문 재사용, 이미지/음성 자산 검증.
- `npm run test:mobile`: 네 화면 크기의 실제 렌더링, 문서/내부 넘침, 학습 글자의 카드 밖 이탈, 터치 가림, 44px 터치 영역, 모든 듣기 버튼의 실제 MP3 재생, 모든 단어 카드/이전/다음, 퀴즈 전 문항·점수·축하/오답·음소거·탭 복귀 검증.
- `TEST_BASE_URL=https://실제앱주소 npm run test:mobile`: 같은 검증을 공개 배포 주소에서 실행.
- 결과는 `artifacts/mobile/report.json`과 스크린샷 44장에 저장합니다. `artifacts/`는 Git에서 제외합니다.

2026-11-07 검증: **320×568, 360×740, 390×844, 430×932 모두 통과**. 화면별 실제 듣기 25회, 정답 7개 100점·오답 1개 86점, 실제 Web Audio 출력 및 MP3 19개 디코딩/비무음 파형을 확인했습니다. [검증 기록과 미리보기](docs/MOBILE-VERIFICATION.md)를 참고하세요. 이는 Chromium 모바일 뷰포트/터치 검증이며 실물 iPhone·Android 기기의 스피커 청음 결과는 아닙니다.

## Cloudflare 배포

기존 구조를 유지합니다.

```sh
npm run build
# output: dist/
npx wrangler deploy --assets ./dist --compatibility-date 2026-11-01
```

Cloudflare Workers의 기존 GitHub 연동 빌드 `Workers Builds: dayun-japanese`가 `main` 반영을 감지합니다. 다른 프로젝트나 Cloudflare 계정 설정을 변경하지 않습니다. 배포별 성공 여부는 해당 커밋의 GitHub Checks에서 확인합니다.
