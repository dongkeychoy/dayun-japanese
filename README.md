# 다윤이의 일본어 미션 · 7가지 동사 활용형 (v4)

## 현재 앱
- 모바일 한 화면 고정, 세로 스크롤 없이 훈련·문장·단어·퀴즈의 4개 탭 전환
- DAY 01: 行く（いく）· 가다
- **훈련모드: 가타치처럼 한 줄에 한 활용형씩 7개 모두 표시**
- 순서: 기본형 · 정중형 · 부정형 · 과거형 · 과거부정형 · 연결형 · 진행·상태형
- 일본어 정자체 · 뜻 · 줄마다 일본어 TTS 듣기 버튼
- 문장모드: 일본어 → 히라가나 → 한국어 해석, 발음 재생
- 단어모드: 문장 속 어휘를 그림 카드로 학습
- 퀴즈모드: 활용형 7개를 문장 빈칸 4지선다로 학습, 100점 채점, 정답 박수/오답 효과, 재도전
- 아빠 확인 도장과 학습 기록(localStorage)을 유지
- 레벨 설정 화면은 유지하지만 **7가지 활용형 노출 개수는 레벨에 따라 제한하지 않음**
- 레벨별 문제 난이도 차등화는 앞으로 검토할 사항이며 현재 완성된 기능이라고 주장하지 않음

## 실제 실행에 사용하는 파일
- `public/index.html`: HTML과 기본 스타일, 대표 일러스트
- `public/visual-hotfix-20261103.css`: 기존 화면 보완 스타일
- `public/one-line-7-v4.css`: 이번 7개 한 줄형 훈련 화면 최종 보완
- `public/runtime.js`: **현재 실행되는 JavaScript와 학습 데이터**
- `public/app.js`, `public/lessons.js`, `public/style.css`: 예전 버전으로 현재 실행 경로에서 사용하지 않음

새 DAY를 추가할 때는 현재 `public/runtime.js` 안의 `const lessons = [...]` 배열에 학습 데이터를 추가하세요.

## 검증
- Chromium 모바일 뷰포트에서 320×520, 320×568, 360×640, 360×740, 375×667, 390×844, 430×932의 7가지 크기를 확인.
- 7줄 모두 표시되고 일본어 긴 표현이 가로로 잘리지 않는지 검사.
- 각 크기에서 문장/단어/퀴즈 탭 전환, 퀴즈 7문제 전부 정답 시 100점, 재도전 동작 확인.
- 일부 카카오톡 내장 브라우저의 폰트 확대·접근성 설정은 기기에서 별도 확인 필요.
- TTS 음질과 실제 효과음 볼륨은 다윤이의 휴대폰에서 최종 점검 필요.
