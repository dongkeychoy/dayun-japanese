## 확인한 동작

- 학습 데이터 7가지 활용형 및 7문장/후리가나/해석을 요청 내용과 대조했습니다. 단어는 정확히 5개입니다.
- DOM 글자 범위가 카드 밖으로 이탈하지 않는지, 콘텐츠 내부의 가로/세로 넘침이 있는지, 마지막 행과 하단 영역이 화면 안에 있는지 확인했습니다. 페이지 스크롤을 숨기는 CSS로 검사를 통과시키지 않았습니다.
- 훈련 7개·문장 7개·단어/예문 10개와 효과음 음소거 후 발음 듣기 1회를 화면마다 실제로 눌렀습니다. HTMLMediaElement의 `playing` 이벤트와 실제 `currentTime` 진행을 확인했습니다. 음성 API를 mock으로 대체하지 않았습니다.
- 일본어 MP3 19개 모두 실제 AudioContext에서 디코딩했고, 유효한 길이와 0이 아닌 파형을 확인했습니다.
- 정답 시 점수가 즉시 표시되고, 색 변화·애니메이션·색종이와 합성 축하음/박수의 실제 Web Audio 파형이 발생합니다. 화면마다 정상 실행 중인 AudioContext, 최소 21개 음계 오실레이터와 56개 박수 버퍼 시작을 확인했습니다.
- 오답 시 0점 유지, 부드러운 색 변화, 낮은 효과음 2개 발생을 확인했습니다. 전부 정답이면 100점, 오답 1개이면 86점입니다. 최고 점수 100점이 저장됩니다.
- 퀴즈 답 선택 뒤 탭 왕복, 재도전, 음소거, 단어 카드 양방향 이동 및 끝에서의 버튼 비활성화를 확인했습니다.
- 학습 듣기·단어 이동·퀴즈 답안/다음 버튼은 44×44px 이상이며 다른 요소가 터치를 가리지 않습니다.
- 스크린샷 총 44장을 생성했습니다. 저장소에는 각 크기별 4개 모드의 대표 스크린샷 16장과 [측정 JSON](mobile/report.json)을 남겼습니다.
